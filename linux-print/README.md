# Fb3d2y Print para Linux

Aplicativo para Lubuntu/Ubuntu 64 bits. Usa CUPS para listar impressoras e enviar comandas em modo RAW (ESC/POS).

Instalação: abra o arquivo `fb3d2y-print-linux-amd64.deb` e instale pelo gerenciador de pacotes. Também é possível usar `sudo apt install ./fb3d2y-print-linux-amd64.deb`.

Depois, abra **Fb3d2y Print** no menu de aplicativos, selecione a impressora, copie o código e cole nas configurações de impressão do Fb3d2y Menu. Mantenha o aplicativo aberto durante o expediente.
